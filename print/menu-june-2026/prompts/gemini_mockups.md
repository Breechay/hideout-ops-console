# Gemini Imagen Prompts

Same text as `chatgpt_mockups.md` — Gemini accepts identical photographic prompts.

**Settings when available:**
- Style: Photographic
- Resolution: Highest available (2048+)
- Avoid: Illustrated, painterly, HDR, oversaturated

**Workflow:** Paste prompt → generate 4 → pick 1 → save PNG → import to `psd-templates/` as background layer under texture group.

See `image_generation_reference.md` for post-generation checklist.
