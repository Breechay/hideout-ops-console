# Typography Reference

See `01_BRAND_SYSTEM.md` for tokens. Quick scale for print:

| Element | Font | Size (print) |
|---------|------|--------------|
| Placement headline | Cormorant Garamond Italic | 26–48pt |
| Section label | DM Sans Medium | 10pt, kerning 0.9 |
| Body | DM Sans Regular | 12–14pt |
| Metadata / hours | DM Sans Regular | 9–11pt, muted cream |
| Prices | DM Mono | 12–13pt |
| Wordmark | Cormorant Garamond Italic | 18–40pt |

**Line spacing:** Body 1.4–1.6. Display headlines generous leading.

**Alignment:** Lobby + Sunday exit = left-aligned headlines. Counter tent = centered QR, left or center headline per format.

**Case:** `hideout` lowercase in wordmark. Category labels uppercase with letterspacing (match column boards).
