# 03 — Hideout Miami · Placement Cards
## Six placements · One design family

---

## The rule for all six

Same system. Different message. One caramel element each.

If any card could be mistaken for a different brand, it's wrong.
If any card looks like a different café's promotion, it's wrong.
If any two cards feel visually inconsistent with each other, fix the outlier.

---

## Placement 1 — Counter NFC/QR Card

**Format:** 3.5" × 2" business card (horizontal) OR 4" × 6" tent card (vertical)  
**Location:** Register, tip area, pickup counter  
**QR URL:** `https://hideoutmiami.com/app?source=nfc`  
**Person seeing this:** Someone who just ordered or is paying. They already like Hideout.  
**Job:** Convert them from one-time to two-tap repeat.

### Layout (business card, horizontal)

```
┌────────────────────────────────────┐
│                                    │
│  hideout              [QR  caramel]│
│                        [frame 1"  ]│
│  Your usual —                      │
│  two taps.             [scan below]│
│                                    │
│  Wed–Fri 8–5 · Sat–Sun 10–5        │
└────────────────────────────────────┘
```

### Layout (tent card, vertical)

```
┌──────────────────┐
│                  │
│  hideout         │ ← logo, centered, small
│                  │
│  Your usual —    │ ← Cormorant Garamond Italic, 26pt
│  two taps.       │
│                  │
│  [QR 1.25×1.25"] │ ← centered, caramel frame
│                  │
│  scan to reorder │ ← DM Sans 8pt, muted cream
│                  │
│  Wed–Fri 8–5     │ ← DM Mono 7pt, muted cream
│  Sat–Sun 10–5    │
└──────────────────┘
```

**Caramel element:** QR frame  
**Cormorant Garamond line:** "Your usual — two taps."  
**Copy notes:** Use this headline for the placement near the register (regulars). If near the entrance, consider "Order before you walk over." — same layout.

## Placement 4 — Salon Counter Card

**Format:** 3" × 4" small tent card (vertical)  
**Location:** A Better You salon — checkout counter, mirror stations  
**QR URL:** `https://hideoutmiami.com/app?source=neighbor`  
**Person seeing this:** Client waiting for color, paying at checkout.  
**Job:** Pass the 3-second glance test. One thing.

### Layout

```
┌──────────────────┐
│                  │
│  Two minutes     │ ← Cormorant Garamond Italic, 28pt, cream
│  away.           │
│                  │
│  Terrace coffee  │ ← DM Sans Regular, 11pt, muted cream
│  + toast         │
│                  │
│  [QR 1.1×1.1"]   │ ← caramel frame, centered
│                  │
│  order ·         │ ← DM Sans 8pt, muted cream
│  pickup · done   │
│                  │
└──────────────────┘
```

**Caramel element:** QR frame  
**Cormorant Garamond lines:** "Two minutes / away." — that's the whole card  
**Copy notes:** No hours on this card. It's ambient. The QR shows hours. No "download." The scan is the action.

### Staff script (for salon owner to brief staff)

One sentence. Not a pitch. Just a fact.

## Placement 5 — Sunday Exit Bridge Card

**Format:** 4" × 6" postcard, single-sided  
**Location:** Handed personally at Sunday Morning exit (11AM–2PM)  
**QR URL:** `https://hideoutmiami.com/app?source=weekday`  
**App:** `weekdayBridge` → Today tab + "Same house · weekday pickup." (shipped HideoutApp)  
**Person seeing this:** Someone leaving Sunday Morning. Already loves the house.  
**Job:** Bridge Sunday identity → weekday pickup. One tap when they're ready.

### Layout

```
┌──────────────────────┐
│                      │
│                      │ ← top third: mostly empty
│                      │
│  Same house.         │ ← Cormorant Garamond Italic, 40pt, cream
│  Different room.     │   two lines, left-aligned
│                      │
│  ────────            │ ← caramel rule, SHORT (~25% width), left edge
│                      │
│  Weekday pickup      │ ← DM Sans Regular, 12pt, muted cream
│  on the terrace —    │   line spacing 1.5
│  coffee, toast,      │
│  signatures.         │
│                      │
│  [QR 1.25×1.25"]     │ ← caramel frame, left-aligned or centered
│                      │
│  Wed–Fri 8–5         │ ← DM Mono 9pt, muted cream 60%
│                      │
│            hideout   │ ← logo, bottom-right, small, cream
└──────────────────────┘
```

**Caramel element:** Short rule after headline (directional — pulls eye down to QR)  
**Cormorant Garamond lines:** "Same house. / Different room." — these are fixed. Do not change this copy.  
**Copy notes:** Only weekday hours. Saturday–Sunday they already know. The empty top third is intentional — it breathes. The card should feel like a note left by someone, not a promotional insert.

### Handoff note
This card is handed in person at the exit, not left on a table.
The human handoff is part of the experience.
If you run out, make more before next Sunday.

## Placement 6 — Office/B2B Card

**Format:** 4" × 6" (vertical) or 5.5" × 3.5" (horizontal half-business-card)  
**Location:** Handed to office managers, Expansive/SkyView tenants, event partners  
**QR URL:** `https://hideoutmiami.com/app?source=office`  
**Person seeing this:** Office manager or decision-maker considering a recurring account.  
**Job:** Make the economics clear. One action.

### Layout (4×6 vertical — recommended)

```
┌──────────────────────┐
│                      │
│  hideout    [small]  │ ← logo, top-center
│                      │
│  ────────────────    │ ← hairline
│                      │
│  Office breakfast    │ ← DM Sans Medium, 15pt, cream — left-aligned
│  Gallon cold brew    │
│                      │
│  ────────────────    │ ← hairline
│                      │
│  $16/person          │ ← DM Mono, 16pt, cream — left-aligned
│  $45/gallon          │
│  48hr lead           │ ← DM Sans Regular, 11pt, muted cream
│                      │
│  Egg toast included  │ ← DM Sans Regular, 10pt, muted cream
│  Terrace pickup      │
│                      │
│  [QR 1.25×1.25"]     │ ← caramel frame, centered
│                      │
│  ────────────────    │ ← hairline
│                      │
│  Standing weekly     │ ← DM Sans Regular, 10pt, muted cream
│  orders welcome      │
│                      │
│  ___________________  │ ← blank line (handwrite contact here)
│  hideoutmiami.com    │ ← DM Mono 8pt, muted cream 50%
└──────────────────────┘
```

**Caramel element:** QR frame  
**Primary type:** DM Mono for prices — this is pricing, not poetry. Monospace = precision.  
**Copy notes:** "Standing weekly orders welcome" is the B2B pitch in 4 words. The blank line at bottom is intentional — write your number on it when handing to a specific person. It personalizes without redesigning.
